## Decisions

- `dispositors` は root 直下に置く。
- 各要素は、単一rootへ到達する場合は `root`、循環する場合は `loop` を持つ。
- `dispositors` 内のペアは、読みやすさと将来の拡張を考えて `{"point": "...", "dispositor": "..."}` のオブジェクトにする。
- `points` と `houses.cusps` の各要素から `dispositor` は削除する。
- 追加修正で、`dispositors` は主要10天体だけを対象にすることにした。house cusp、angle、小惑星、ノード、感受点は `dispositors` には含めない。
- アスペクトでは、ノード同士、アングル同士、Vertex/Anti Vertex同士、house cuspを対象にしない。
