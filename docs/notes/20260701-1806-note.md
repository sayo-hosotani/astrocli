## Decisions

- `chartRuler` は `sign` と `ruler` を出力する。
- `stelliums` は `kind` を `sign` または `house`、`name` をサイン名またはハウス番号、`points` を該当点一覧として出力する。
- `complexAspects` は `pattern`、`points`、成立に使った `aspects` を出力する。
- 神の指の判定には quincunx を複合アスペクト専用の判定角として追加した。通常の `aspects` 一覧には出力しない。
