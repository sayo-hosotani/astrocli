- [x] JPL Horizonsから対象日時の小惑星状態ベクトルを取得する。
- [x] `GravitySimulator` に小惑星状態ベクトルを渡す。
- [x] 同時刻の地球状態ベクトルを取得し、小惑星の地球基準ベクトルへ変換する。
- [x] EQJからECLへ回転し、黄経を算出する。
- [x] 既存の `BodyPosition` と同じ形式に整形する。
