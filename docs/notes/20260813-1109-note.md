# 支援センター提出文書の推敲

## Plan

### 原文整理

理由: 提出先が事実関係と支援ニーズを短時間で把握できるよう、確認済み事実、学校からの説明、保護者の認識を区別する必要がある。

- [x] 添付原文を通読する。
- [x] 時系列、現在の困難、これまでの対応、改善要望を抽出する。
- [x] 日付および表記上の要確認箇所を抽出する。

### 提出稿作成

理由: 長い経過を残しながら要望を埋もれさせないため、要約本文と詳細資料に分ける。

- [x] 相談の趣旨、現状、要望を本文にまとめる。
- [x] 発達・療育歴と学校生活の詳細を別紙として整理する。
- [x] 推測的・断定的な表現を、根拠が分かる客観的な表現へ改める。

### 成果物確認

理由: 提出に使用できるWord文書として、内容とレイアウトを確認する。

- [x] DOCXを作成する。
- [x] DOCXの構造、見出し、表幅、セル幅、箇条書き、メタデータを監査した。
- [x] 提出前に保護者が確認すべき箇所を明示する。

## Plan変更

- 原文は長く、要望が末尾に埋もれるため、提出本文、学校生活の詳細経過、発達・療育歴の三部構成へ変更した。
- 個人情報を含む提出稿であるため、成果物はプロジェクトの `deliverables/` にのみ保存した。
- DOCXの画像レンダリングを試みたが、実行環境にLibreOfficeおよびレンダリング用Python依存関係がなかった。構造監査へ切り替え、ZIP整合性、ページ設定、見出し、箇条書き、表のDXA幅、メタデータを確認した。

## 最終結果

- `deliverables/支援センター提出文書_推敲案.docx` を作成した。
- 事実、学校からの説明、保護者の認識が区別できる表現へ改めた。
- 支援センターへの具体的な依頼と、学校で検討する支援例を本文前半に配置した。
- 原文の年月と年齢が矛盾する2024年2月7日の記録、および作成日より後の2026年8月21日のWISC-Vについて、提出前の確認事項を付した。
