# Note

## Topic

小惑星ツールは常にキロン、セレス、パラス、ジュノー、ベスタの5件をまとめて計算するため、対象指定入力を削除する。

## Decisions

- `asteroid` サブコマンドから `--input` を削除する。
- 標準入力、テキスト入力、JSON入力による対象指定を削除する。
- `--output` は計算結果の出力先として維持する。
- 固定5件はコード内に保持し、追加が必要な場合はコード修正で対応する。
