# ライセンスファイル作成

## 主題

AstroCLIのライセンスを明文化し、本体をMIT、テストをAGPLと分けられるか確認する。

## 決定事項

- AstroCLIのリポジトリ全体を `AGPL-3.0-only` とする。
- ルートに標準的なファイル名の `LICENSE.md` を置く。
- `LICENSE.md` にはGNU Affero General Public License Version 3の全文を収録する。
- READMEにライセンスと、Swiss EphemerisのデュアルライセンスではAGPLを選択していることを明記する。
- `goal.md` は、完了済みの機能goalに影響しないライセンス文書整備のため変更しない。

## 判断の背景

`tests/AstroCli.Tests` だけでなく、`src/AstroCli/AstroCli.csproj` が
`SharpAstrology.SwissEph` 0.4.2を直接参照している。
`src/AstroCli/NatalChartCalculator.cs` も同ライブラリを本体計算で直接使用するため、
現状を「本体MIT、テストAGPL」と分離することは実態に合わない。

`SharpAstrology.SwissEph` 0.4.2のNuGetパッケージはAGPL-3.0をライセンスとして指定している。
同梱のSwiss Ephemerisライセンス通知とAstrodienst公式プログラミング文書は、
AGPLを選ぶ場合、Swiss Ephemerisを使用するソフトウェアプロジェクト全体を
AGPLまたは互換ライセンスとするよう説明している。

将来、MITへ変更したい場合は、少なくとも次のいずれかを別途検討する。

- 本体から `SharpAstrology.SwissEph` とSwiss Ephemeris由来部分を除去し、互換性のある計算実装へ置き換える。
- Swiss Ephemeris Professional Licenseを取得し、SharpAstrology側を含む権利関係と再ライセンス条件を確認する。

## Plan Changes

### 変更内容

当初候補の「本体MIT、テストAGPL」を採用せず、リポジトリ全体を
`AGPL-3.0-only` とするplanへ変更した。

### 変更理由

AGPL依存はテスト限定ではなく、本体プロジェクトの直接依存かつ実行時依存だった。
また、Swiss Ephemerisの公式条件が、AGPLを選ぶソフトウェアプロジェクト全体への適用を明記していた。

### 変更後の進め方

SharpAstrologyパッケージに同梱された標準AGPL Version 3全文を
`LICENSE.md` に使用し、READMEにも適用ライセンスと選択したデュアルライセンス側を明記した。

## Final Result

- `LICENSE.md` を作成し、AstroCLI全体を `AGPL-3.0-only` として明文化した。
- READMEからライセンス全文へ移動できるようにした。
- 現在の依存関係では、本体MIT・テストAGPLという分離は採用できないことを記録した。
