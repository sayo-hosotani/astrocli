## Result

現在のJSONには `ra`、`dec`、`azimuth`、`altitude`、`distanceAu` が含まれるが、`GravitySimulator` に必要な `x`、`y`、`z`、`vx`、`vy`、`vz` が含まれない。

そのため、現在のJSONは「指定日時・指定地点から見た見かけ位置の結果」としては使えるが、このJSONだけを入力にしてAstronomy Engineで小惑星の軌道を再計算または別時刻へ伝播することはできない。

再計算可能にするには、各小惑星に少なくとも次の情報を追加する必要がある。

- `stateVector.epoch`
- `stateVector.origin`: `sun`
- `stateVector.frame`: `EQJ`
- `stateVector.units.position`: `AU`
- `stateVector.units.velocity`: `AU/day`
- `stateVector.x`
- `stateVector.y`
- `stateVector.z`
- `stateVector.vx`
- `stateVector.vy`
- `stateVector.vz`

- `GravitySimulator` が `Body.Sun` などの原点、EQJ、AU、AU/dayの状態ベクトルを必要とすることを確認した。
