## Decisions

- `aspects[].angle` は解釈上不要なため出力から削除した。
- `planets`、`asteroids`、`angles`、`objects` は root 直下の `points` に統合した。
- 各pointには `type` を持たせ、`planet`、`asteroid`、`angle`、`object` を出力する。
- 各感受点やハウス内にあった `sabian` は削除し、root直下の `sabianSymbols` に集約した。
- ハウスカスプのサビアン情報も `sabianSymbols` に含める。サビアン情報を一箇所に集めるほうが、出力の重複と参照先のばらつきを避けられるため。
- ノースノードとサウスノードは `SharpAstrology` の `Planets` として計算しているが、旧 `objects` グループに属していた意味を優先し、出力 `type` は `object` とした。

## Background

複数チャートのアスペクト算出を考えると、`planets`、`asteroids`、`objects` を毎回結合して対象点を作るより、チャートごとに `points` を持つ形のほうが扱いやすい。

想定例:

```json
{
  "charts": {
    "natal": {
      "points": {}
    },
    "transit": {
      "points": {}
    }
  },
  "aspects": []
}
```

この形なら、同一チャート内アスペクトも複数チャート間アスペクトも、点の参照方法を統一しやすい。

## Result

- `ChartOutput` を `points` と `sabianSymbols` 中心の出力モデルに変更した。
- `AspectOutput` から `Angle` を削除した。
- `NatalChartCalculator` は内部の `ChartPoint` に `Type` を追加し、出力時に `PointOutput` へ変換するようにした。
- READMEの説明とJSON例を新スキーマに更新した。
- テストを新スキーマへ更新し、旧rootプロパティが出力されないことと、サビアン情報が `sabianSymbols` に移動していることを確認するようにした。
