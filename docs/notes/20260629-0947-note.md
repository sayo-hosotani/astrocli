## Findings

- Astronomy Engine 2.1.19の `CosineKitty.Body` enumには、対象小惑星が存在しない。
- `CosineKitty.Body` に存在するのは、主要惑星、太陽、月、EMB、SSB、ユーザー定義恒星 `Star1` から `Star8` である。
- `Astronomy.BaryState` と `Astronomy.HelioState` のドキュメントでも、サポート対象は太陽、月、EMB、SSB、主要惑星、またはユーザー定義恒星に限定されている。
- `GravitySimulator` は任意の小天体を扱えるが、呼び出し側が小天体の初期位置と速度を `StateVector` として用意する必要がある。
- キロン、セレス、パラス、ジュノー、ベスタを直接計算する公開APIは確認できなかった。

## Plan Changes

## Final Result

- Astronomy Engineではキロン、セレス、パラス、ジュノー、ベスタを組み込み天体として直接出力できないと判断した。
- 迂回実装は影響範囲が大きいため、ユーザー確認なしには進めない。
- コード変更は行っていない。
