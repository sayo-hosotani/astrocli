## Plan Changes

### Replan 1

変更したこと:

- 小惑星/ノード追加の実装を停止した。
- 途中で追加した `BodiesOutput` と `NatalChartCalculator` の小惑星/ノード変更は戻した。

変更理由:

- `SharpAstrology.SwissEph` の `Planets` enumにはChiron、Ceres、Pallas、Juno、Vesta、NorthNode、SouthNodeが存在する。
- しかし、現在使用しているMoshier sourceでは少なくともChironが未対応で、CLI実行時に `UnsupportedBodyException: Body Chiron is not supported by ephemeris source Moshier.` が発生した。
- 追加切り分けでは、Moshierで `NorthNode` と `SouthNode` は計算できた。
- 追加切り分けでは、Moshierで `Chiron` と `Ceres` は `UnsupportedBodyException` になった。
- ユーザー要望は「使えるなら追加」なので、Moshierのみの現在方針では対象天体一式を安全に追加できない。

変更後のplan:

- Moshierのみで実装する場合は、現時点では小惑星追加を見送る。
- 小惑星を追加する場合は、Swiss Ephemeris `.se1` ファイルを使う高精度/Swiss sourceへ切り替えるか、別の小惑星対応ライブラリを調査する。
- ノードのみTrue Nodeとして追加することは可能そうだが、今回の「小惑星も追加」という依頼とは分けて判断する。
