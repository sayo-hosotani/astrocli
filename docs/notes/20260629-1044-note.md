# Note

## Topic

JPL Horizons APIとCosineKitty Astronomy Engineを使い、既知小惑星の地上観測位置をJSON出力するC#ツールを追加する。

## Decisions

- 実装言語は既存プロジェクトに合わせてC#とする。
- 小惑星ツールは既存 `astrocli` の `asteroid` サブコマンドとして追加する。
- 対象小惑星の入力は、1行1IDのテキストとJSONの両方を扱う。
- 入出力はファイルと標準入出力の両方を扱う。
- Horizons APIから状態ベクトルを取得し、Astronomy Engineの `GravitySimulator` に渡して指定日時へ伝播する。
- MVPでは大気差補正を使わない。
- ローカルキャッシュと `--refresh` は今回のMVPから外す。HTTP取得部分を差し替え可能にし、テストはfixtureで安定化する。
