## Changes To Plan

- `angles` と `houses.cusps` にもハウス情報を出してよいというユーザー補足があった。
- 実装上は nullable な `BodyPosition.House` と `JsonIgnoreCondition.WhenWritingNull` で対象カテゴリだけに出せたため、当初の `planets` / `asteroids` / `objects` 限定を維持した。
- 夜チャートの Part of Fortune の期待ハウスを当初 `house2` と見積もったが、該当日時のハウスカスプでは `house4` が正しいためテスト期待値を修正した。

## Decisions

- ハウス所属は「対象黄経が、あるカスプから次のカスプまでの範囲に入る場合、そのカスプのハウスに所属する」と定義した。
- 0度またぎは、黄経差を0-360度に正規化して判定する。
- カスプ上に完全一致した場合は、そのカスプのハウスに所属する。
- `houses.cusps` と `angles` は `BodyPosition` を共有するが、`house` は null のままにしてJSONには出力しない。

## Result

- `BodyPosition` に nullable な `House` を追加した。
- `NatalChartCalculator` でPlacidusの12ハウスカスプから所属ハウスを判定し、主要天体、小惑星、感受点へ付加した。
- `AsteroidBodyPositionCalculator` は任意のハウス判定関数を受け取れるようにし、未指定時は従来通りハウス情報なしで動く。
- READMEのJSON例に `house` を追記した。
- テストで対象カテゴリには `house` が出ること、対象外カテゴリには出ないことを確認するよう更新した。
