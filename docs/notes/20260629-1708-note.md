## Current Decisions

- `plan.md` はプロジェクトルール上使用しない。作業planはこの議事録に記録する。
- `BodyPosition` はJSON用の型として扱い、数値黄経と識別子は内部用 `ChartPoint` に分離する。
- サビアンはジョーンズ版の英語シンボル名一覧を `SabianSymbols` として組み込む。解釈文は組み込まない。
- ディスポジターは伝統ルーラーではなくモダンルーラーを採用する。Aries Mars、Taurus Venus、Gemini Mercury、Cancer Moon、Leo Sun、Virgo Mercury、Libra Venus、Scorpio Pluto、Sagittarius Jupiter、Capricorn Saturn、Aquarius Uranus、Pisces Neptune。
- アスペクトは主要5種を対象にする。conjunction 0、opposition 180、trine 120、square 90、sextile 60。orbは6度以内。
- アスペクト対象は主要10天体、小惑星5件、objects 6件の合計21ポイントとする。anglesとhouse cuspsは対象外とする。
- カルミネート天体は主要10天体のうち、MCから黄道順の距離が最小のものとする。

## Changes To Plan

- ユーザーから `plan.md` を一時的に作ってもよい、または議事録をplan代わりに使ってよいという補足があった。
- プロジェクトルールでは `plan.md` を使用しないため、`docs/notes/20260629-1708-note.md` を先に作成し、作業planと進捗を記録した。
- 小惑星のように内部黄経が度数境界の直前で、表示上は秒丸めにより次の度数になるケースがあった。サビアン度数はJSONに表示される黄経と整合するよう、秒丸め後の黄経から計算する方針に変更した。
- ジョーンズ版であればパブリックドメインになっているはずというユーザー指摘を受け、英語シンボル名一覧を組み込むことにした。
- 360件のシンボル名は James Burgess のサイン別サビアン一覧ページから抽出した。サイト独自の `Quiz:` リンクや不可視文字は除外した。
- ユーザー指摘により、`sabian` は `index` と `symbol` のみに絞った。
- ユーザー指摘により、`aspects` は `point1` / `point2` ではなく `points` 配列で2点を表す形にした。

## Result

- `BodyPosition` から `Name` を削除した。通常チャートJSONでは、各ポイントの識別子は `planets.sun` などのプロパティ名で表す。
- 内部計算用に `ChartPoint` を追加し、数値黄経、JSONキー、所属ハウスを保持するようにした。
- `BodyPosition` に `dispositor` と `sabian` を追加した。`house` は従来通り、主要10天体、小惑星、objectsにだけ出力し、houses.cuspsとanglesには出力しない。
- `SabianSymbols` を追加し、360件のジョーンズ版英語シンボル名を組み込んだ。
- `sabian` に `symbol` を追加し、出力項目は `index` と `symbol` のみにした。
- チャート直下に `aspects` を追加した。対象は主要10天体、小惑星5件、objects 6件で、anglesとhouse cuspsは対象外。
- `aspects` の2点表現を `points: ["sun", "moon"]` の形にした。
- チャート直下に `culminatingPlanet` を追加した。
- READMEの通常チャート例から `name` を削除し、新規出力を追記した。
- テストで `name` が出力されないこと、`dispositor` / `sabian` が出力されること、アスペクト例、カルミネート天体を確認するようにした。
