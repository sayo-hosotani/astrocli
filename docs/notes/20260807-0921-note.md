# 将来のMIT化対応メモ

## 主題

AstroCLIを将来MITライセンスへ変更するために、着手前に満たすべき条件と確認事項を記録する。

## 現在の決定

- 現在のAstroCLIは `AGPL-3.0-only` とする。
- 本体が `SharpAstrology.SwissEph` を直接使用している間は、MITへ変更しない。
- MIT化は、依存関係・計算精度・著作権をまとめて確認する独立した作業として扱う。

## MIT化の着手条件

次の条件を満たせる見通しが立った時点で、MIT化のgoalを作成して着手する。

1. 本体から `SharpAstrology.SwissEph` とSwiss Ephemeris由来の実装を除去、またはMITと両立する権利条件に置き換えられる。
2. 代替の天文計算が、現在必要な天体位置、ノード、アングル、ハウスカスプ、Vertex、Lilithを扱える。
3. 代替実装の値を既存スナップショット、信頼できる参照値、入力境界条件で検証できる。
4. 本体・テスト・配布物のすべての直接依存と推移依存について、MIT配布と矛盾しないライセンスを確認できる。
5. リポジトリへの寄稿者が増えている場合は、MITへの再ライセンスに必要な権利・同意を確認できる。

## 将来の作業項目

### 依存の切り離し

MIT化の前提となるため、最初に実施する。

- [ ] `SharpAstrology.SwissEph` の本体使用箇所とテスト使用箇所を棚卸しする。
- [ ] 天体位置、ノード、アングル、ハウスカスプ、Vertex、Lilithごとに代替計算手段を決める。
- [ ] AGPL依存を含まない実装またはライブラリへ置き換える。
- [ ] 本体プロジェクトから `SharpAstrology.SwissEph` の参照を削除する。
- [ ] テストのAGPL依存も削除または別の参照値へ置き換える。

### 精度と動作の検証

計算エンジンの差し替えは出力値へ影響するため、ライセンス確認とは別に品質を確認する。

- [ ] 既存のCLI出力形式とエラー動作を維持する。
- [ ] 固定日時・固定地点のスナップショットを更新または維持する根拠を記録する。
- [ ] 天体位置・ハウスカスプ・感受点を独立した参照値と比較する。
- [ ] 対応範囲、時刻系、座標系、近似精度をREADMEに明記する。

### ライセンス監査と切り替え

置き換え後に、実際の配布物まで含めてMITと整合することを確認する。

- [ ] `dotnet list package --include-transitive` などで依存一覧を取得する。
- [ ] 各依存のライセンス、著作権表示、再配布条件を確認する。
- [ ] 自作コードの著作権者と寄稿者の再ライセンス権限を確認する。
- [ ] `LICENSE.md` をMIT本文へ変更し、READMEと配布メタデータを更新する。
- [ ] 必要な第三者ライセンス通知を配布物へ含める。

## 商用ライセンスを検討する場合の注意

Swiss Ephemeris Professional Licenseの取得だけでMIT化できるとは限らない。
`SharpAstrology.SwissEph` 自体の著作権・ライセンス条件、および配布形態についても、
別途、権利者または専門家に確認する。
