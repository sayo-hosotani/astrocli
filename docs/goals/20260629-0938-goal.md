# Goal

## Objective

西洋占星術ネイタル固定のまま、SharpAstrology.SwissEph Moshierでプラシーダスの12ハウスカスプをJSON出力に追加する。

## Requirements

### Scope

- 今回は西洋占星術ネイタル固定のままとする。
- CLI入力形式は現状維持とする。
- `location` 出力は現状維持とする。
- `ascendant` 出力は現状維持とする。
- `bodies` の主要10天体出力は維持する。
- 天体位置はtopocentricではなく地心基準で計算する。
- 度数表記は既存どおり60進数文字列にする。
- ハウスシステムはプラシーダスとする。

### Engine

- `SharpAstrology.SwissEph` を使用する。
- `SharpAstrology.SwissEph` はMoshierモードで使用する。
- Swiss Ephemeris `.se1` ファイルは使用しない。
- JPL `.eph` ファイルは使用しない。
- C由来のネイティブDLLは使用しない。
- AGPL-3.0のライセンス制約は承知のうえで進める。

### Houses

- JSON出力に `houses` を追加する。
- `houses.system` は `placidus` とする。
- `houses.cusps.house1` から `houses.cusps.house12` を出力する。
- 各house cuspには `name`、`eclipticLongitude`、`sign`、`degreeInSign` を含める。
- 各house cuspの度数表記は既存と同じ60進数文字列にする。
- `house1` は `ascendant` と同じ黄経を表す。

## Acceptance Criteria

- `astrocli "1989-07-08 05:19:00 +09:00" "35°41’22″N,139°41’30″E"` が成功する。
- 既存の `inputDateTime`、`utcDateTime`、`system`、`chart`、`location`、`ascendant` 出力は維持される。
- 既存の主要10天体 `bodies` 出力は維持される。
- JSON出力に `houses` が含まれる。
- `houses.system` は `placidus` である。
- `houses.cusps` に `house1` から `house12` が含まれる。
- 各 `houses.cusps.*` には `name`、`eclipticLongitude`、`sign`、`degreeInSign` が含まれる。
- 各 `houses.cusps.*.eclipticLongitude` は `15°40’12″` のような60進数文字列である。
- `houses.cusps.house1.eclipticLongitude` は `ascendant.eclipticLongitude` と一致する。
- 固定日時・固定位置のスナップショットテストで12ハウスカスプを検証する。
- READMEにプラシーダスハウス出力を記載する。
- `dotnet build AstroCli.slnx` が成功する。
- `dotnet test AstroCli.slnx --no-build` が成功する。
