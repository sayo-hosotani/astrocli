# Goal

## Objective

小惑星ツールで、固定対象の小惑星名からJPL Horizons用IDへ内部変換できるようにする。

## Requirements

### Scope

- 既存の `asteroid` サブコマンドを維持する。
- 対象小惑星は、キロン、セレス、パラス、ジュノー、ベスタに固定する。
- 入力では日本語名、英名、既存のID指定を扱えるようにする。
- 固定対象を追加する必要が出た場合は、コード修正で対応する。
- 既存のテキスト入力、JSON入力、標準入出力、ファイル入出力は維持する。

### Name Mapping

- キロンは `2060;` に変換する。
- セレスは `1;` に変換する。
- パラスは `2;` に変換する。
- ジュノーは `3;` に変換する。
- ベスタは `4;` に変換する。
- 英名は大文字小文字を区別せずに扱う。
- 日本語名は一般的な長音表記を扱う。

### Output

- 出力JSONでは、入力された名称を `id` として維持する。
- `horizonsCommand` には変換後のJPL Horizons用IDを出力する。

## Acceptance Criteria

- テキスト入力で `キロン`、`セレス`、`パラス`、`ジュノー`、`ベスタ` を読み、順に `2060;`、`1;`、`2;`、`3;`、`4;` に変換できる。
- テキスト入力で `chiron`、`ceres`、`pallas`、`juno`、`vesta` を読み、順に `2060;`、`1;`、`2;`、`3;`、`4;` に変換できる。
- JSON入力で名称指定を読み、固定IDへ変換できる。
- 既存の数値ID入力も引き続き扱える。
- READMEに固定対象名と入力例を記載する。
- `dotnet build AstroCli.slnx` が成功する。
- `dotnet test AstroCli.slnx --no-build` が成功する。
