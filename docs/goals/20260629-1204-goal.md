# Goal

## Objective

小惑星ツールの対象を固定5件にし、対象指定の入力パラメータを削除する。

## Requirements

### Scope

- 既存の `asteroid` サブコマンドを維持する。
- `asteroid` サブコマンドは、常にキロン、セレス、パラス、ジュノー、ベスタの5件をまとめて計算する。
- 対象小惑星の入力ファイル、標準入力、JSON入力、テキスト入力は削除する。
- `--input` オプションは削除する。
- `--output` オプションは維持し、標準出力またはファイル出力を選べるようにする。
- 観測日時と観測位置の入力は維持する。
- 固定対象を追加する必要が出た場合は、コード修正で対応する。

### Fixed Targets

- キロンは `2060;` を使う。
- セレスは `1;` を使う。
- パラスは `2;` を使う。
- ジュノーは `3;` を使う。
- ベスタは `4;` を使う。

### Output

- 出力JSONの `asteroids` には常に5件を含める。
- 各小惑星の `id` は日本語名にする。
- 各小惑星の `horizonsCommand` にはJPL Horizons用IDを出力する。

## Acceptance Criteria

- `astrocli asteroid --at "2026-06-29 22:00:00 +09:00" --location "35°41’22″N,139°41’30″E"` の形式で実行できる。
- `astrocli asteroid --at "2026-06-29 22:00:00 +09:00" --location "35°41’22″N,139°41’30″E" --output result.json` の形式でファイル出力できる。
- `--input` を指定すると不正引数として非ゼロ終了する。
- 標準入力に依存せず、入力がなくても固定5件を計算する。
- JSON出力の `asteroids` に、キロン、セレス、パラス、ジュノー、ベスタの5件が含まれる。
- READMEに入力不要の使い方と固定対象を記載する。
- 不要になった小惑星入力パーサを削除する。
- `dotnet build AstroCli.slnx` が成功する。
- `dotnet test AstroCli.slnx --no-build` が成功する。
