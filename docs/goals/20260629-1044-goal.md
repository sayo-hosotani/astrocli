# Goal

## Objective

JPL Horizons APIから既知小惑星の初期状態ベクトルを取得し、CosineKitty Astronomy Engineで地球上の指定位置から見た小惑星位置をJSON出力するC#ツールを追加する。

## Requirements

### Scope

- 既存の西洋占星術ネイタルCLI出力は維持する。
- 新しい小惑星ツールは既存CLIのサブコマンドとして追加する。
- 実装言語はC#とする。
- 出力形式はJSONとする。
- 対象小惑星の入力はJSONまたは単純なテキスト列挙を受け付ける。
- 入力はファイル指定と標準入力の両方を扱えるようにする。
- 出力はファイル指定と標準出力の両方を扱えるようにする。
- 観測日時は既存CLIと同じ `"yyyy-MM-dd HH:mm:ss zzz"` 形式を扱う。
- 観測位置は既存CLIと同じ `"latitude,longitude"` 形式を扱う。

### Horizons

- JPL Horizons APIを使用して、小惑星ごとの状態ベクトルを取得する。
- Horizonsから取得する状態ベクトルは、CosineKitty Astronomy Engineの `GravitySimulator` に渡せるよう、EQJ、AU、AU/dayとして扱う。
- HTTP取得部分はテストで差し替えられる設計にする。
- API取得に失敗した場合は、標準エラーに原因が分かるエラーを出し、非ゼロ終了する。

### Calculation

- `CosineKitty.AstronomyEngine` を使用する。
- 小惑星の伝播には `GravitySimulator` を使用する。
- 出力には少なくとも小惑星ID、観測日時、観測位置、RA、Dec、azimuth、altitude、distanceAuを含める。
- 座標値は数値で出力する。
- 大気差補正はMVPでは使用しない。

## Acceptance Criteria

- `astrocli asteroid --at "2026-06-29 22:00:00 +09:00" --location "35°41’22″N,139°41’30″E" --input asteroids.txt` の形式で実行できる。
- `astrocli asteroid --at "2026-06-29 22:00:00 +09:00" --location "35°41’22″N,139°41’30″E" --input asteroids.json --output result.json` の形式で実行できる。
- `--input -` または入力指定なしで標準入力から対象小惑星の列挙を読める。
- `--output -` または出力指定なしでJSONを標準出力に出せる。
- 単純なテキスト入力では、1行1小惑星IDを読める。
- JSON入力では、小惑星IDの配列またはオブジェクト形式を読める。
- HTTP取得部分を差し替えたテストで、Horizonsレスポンスから状態ベクトルをパースできる。
- テストで、小惑星位置JSONにRA、Dec、azimuth、altitude、distanceAuが含まれることを検証する。
- READMEに小惑星ツールの使い方、入力例、出力例を記載する。
- `dotnet build AstroCli.slnx` が成功する。
- `dotnet test AstroCli.slnx --no-build` が成功する。
