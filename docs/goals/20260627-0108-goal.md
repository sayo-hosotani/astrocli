# Goal

## Objective

西洋占星術ネイタル固定のまま、CLI入力に位置情報を追加し、JSON出力に `location` と `ascendant` を追加する。

## Requirements

### CLI Input

- 第1引数は日時とする。
- 日時形式は既存どおり `"yyyy-MM-dd HH:mm:ss zzz"` とする。
- 第2引数は位置情報とする。
- 位置情報形式は `"latitude,longitude"` とする。
- 緯度は `度°分’秒″N/S` の60進法とする。
- 経度は `度°分’秒″E/W` の60進法とする。
- `N/E` は正、`S/W` は負のdecimal degreeとして内部で扱う。
- 今回は西洋占星術ネイタル固定のままとする。

入力例:

```bash
astrocli "1989-07-08 05:19:00 +09:00" "35°41’22″N,139°41’30″E"
```

### JSON Output

- 既存の `inputDateTime`、`utcDateTime`、`system`、`chart`、`bodies.sun`、`bodies.moon` の出力は維持する。
- JSON出力に `location` を追加する。
- `location` には、入力位置を60進法文字列として含める。
- JSON出力に `ascendant` を追加する。
- `ascendant` はASC（上昇点）の黄経を表す。
- `ascendant` の度数表記は既存の太陽/月と同じ60進数文字列にする。
- `ascendant` には星座名とサイン内度数を含める。

## Acceptance Criteria

- `astrocli "1989-07-08 05:19:00 +09:00" "35°41’22″N,139°41’30″E"` が成功する。
- 上記コマンドのJSON出力に `location` が含まれる。
- `location.latitude` は `35°41’22″N` として出力される。
- `location.longitude` は `139°41’30″E` として出力される。
- 上記コマンドのJSON出力に `ascendant` が含まれる。
- `ascendant.eclipticLongitude` は `15°40’12″` のような60進数文字列である。
- `ascendant.sign` が出力される。
- `ascendant.degreeInSign` は `15°40’12″` のような60進数文字列である。
- 既存のSun/Moon出力は維持される。
- 位置情報のパースについて、`N/E` と `S/W` の正負変換をテストする。
- ASC出力について、固定日時・固定位置のテストを追加または更新する。
- `dotnet build AstroCli.slnx` が成功する。
- `dotnet test AstroCli.slnx --no-build` が成功する。
