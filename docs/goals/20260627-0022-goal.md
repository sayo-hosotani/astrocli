# Goal

## Objective

AstroCLIのJSON出力に含まれる度数表記を10進数から60進数文字列に変更し、.NET更新後に `.slnx` を再度利用できるか確認する。

## Requirements

### Degree Output

- JSON出力の度数は、10進数ではなく60進数文字列にする。
- 形式は `15°40’12″` のように、度・分・秒を含める。
- 対象は `bodies.sun` と `bodies.moon` の `eclipticLongitude` と `degreeInSign`。
- 既存の天体位置計算は維持する。
- 丸めは秒単位で行う。

### Slnx

- .NET SDK更新後に `.slnx` を再度利用できるか確認する。
- `.slnx` で `dotnet build` と `dotnet test` ができるか確認する。
- `.slnx` が利用できる場合は、ビルド/テスト手順を `.slnx` ベースに更新する。
- `.slnx` が利用できない場合は、理由を議事録に残し、既存のプロジェクト単位手順を維持する。

## Acceptance Criteria

- `astrocli "1989-07-08 05:19:00 +09:00"` のJSON出力で、太陽/月の `eclipticLongitude` と `degreeInSign` が60進数文字列になる。
- 出力例は `15°40’12″` のような度・分・秒形式である。
- 固定日時のスナップショットテストが60進数文字列を検証している。
- Astronomy Engineとの比較テストは、内部計算値を秒単位に丸めた60進数文字列として比較している。
- `.slnx` でビルド/テストできるか再確認されている。
- `.slnx` が使える場合、READMEと `.agents/skills` のビルド/テスト手順が `.slnx` ベースに更新されている。
- `.slnx` が使えない場合、理由が議事録に記録され、READMEと `.agents/skills` は利用可能な手順を示している。
