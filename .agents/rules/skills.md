# Skill Rules

## What To Put In Skills

このセクションでは、skillsに何を書くかを定義する。

`.agents/skills` には、繰り返し使う作業手順を書く。

skillsに書くもの:

- ビルド手順
- テスト手順
- リリース手順
- 議事録作成手順
- goal作成手順
- goal設定手順
- goal達成確認手順
- 手順に必要なコマンド
- 作業後の確認観点
- 作業で作成または更新する成果物

## When To Create A Skill

このセクションでは、いつskillsを作るかを定義する。

次の場合はskillを作成または更新する。

- 同じ作業を複数回行う見込みがある。
- 作業に決まった手順、コマンド、確認観点がある。
- 作業の成果物や保存場所が決まっている。
- Codexが次回以降も同じ手順を再利用するべきである。

## What Not To Put In Skills

- 一度きりの作業内容。
- 現在のgoalそのもの。
- 検討経緯や意思決定の背景。
- 常に守る禁止事項や判断基準。

常に守る禁止事項や判断基準は `.agents/rules` に書く。
